# FoodHub – End-to-End Data Analytics Project

## Project Overview

FoodHub is a mini data analytics portfolio project based on a synthetic food delivery dataset.

The objective was to analyze food delivery operations, sales performance, customer orders and restaurant performance using Excel, MySQL, Power BI and Python.

## Tools Used

- **Excel:** Data cleaning, duplicate identification, missing-value handling and initial analysis
- **MySQL:** SQL queries, filtering, grouping and joins
- **Power BI:** Data modeling, KPI measures, interactive dashboards and slicers
- **Python:** Pandas for exploratory data analysis and Matplotlib for visualizations

## Dataset Overview

The project consists of seven related datasets:

| Dataset | Records |
|---|---:|
| Orders (cleaned) | 3,000 |
| Customers | 1,000 |
| Restaurants | 60 |
| Menu Items | 180 |
| Delivery Partners | 150 |
| Payments | 3,000 |
| Returns | 89 |

All data is synthetic and used for learning and portfolio demonstration.

## Python Exploratory Data Analysis

The following analyses were completed:

1. Total sales revenue
2. City-wise sales performance
3. Monthly sales trend
4. Top 10 restaurants by revenue

## Key Business Insights

- FoodHub generated ₹17.03 lakh in revenue from 2,643 delivered orders.
- Bengaluru contributed the highest city-wise revenue at ₹3,30,166.86.
- August 2025 recorded the highest monthly sales at ₹1,60,602.92.
- Royal Bites 2 was the highest-revenue restaurant, generating ₹46,111.90.
- February 2025 recorded the lowest monthly revenue at ₹1,26,878.78.

## Dashboard

The Power BI dashboard includes sales KPIs, order status analysis, monthly trends, city performance, restaurant performance, payment analysis and delivery metrics.

Interactive slicers allow filtering by city, date, order status and cuisine.

## Conclusion

This project demonstrates an end-to-end analytics workflow, including data preparation, SQL analysis, dashboard development, Python EDA and business insight generation.
